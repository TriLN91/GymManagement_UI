# 08. MEMBER'S CURRENT WORKOUT

## INDEPENDENT WORKSPACE
- Member's Current Workout is an independent workspace.
- Accessed via `Members -> Member List -> View Workout` OR `Workout Builder -> Member's Current Workout`.
- Both paths open the SAME page/workspace. DO NOT duplicate implementation.

## STRUCTURE
- `Member Header` + `Day Selector` + `Workout Summary` + `Exercise List`.

## EXERCISE CARD
- **Exercise media / video** is the primary visual element and must take up significant space.
- Do not make the card a dry data table.
- Target and Actual are smaller informational areas.

## TARGET VS ACTUAL
- Clearly distinguish between:
  - **TARGET**: Set by Trainer
  - **ACTUAL**: Executed by Member
- Tracking types: SET / REP / LOAD, DURATION, DISTANCE, INTERVAL / ROUND.
