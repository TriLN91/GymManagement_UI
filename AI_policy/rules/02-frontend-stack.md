# 02. FRONTEND STACK

## DETECTED STACK
- **Framework**: React 19 + Vite 8
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Class Variance Authority + Tailwind Merge + CLSX
- **UI Primitives**: Radix UI
- **Routing**: React Router v7
- **State Management**: Zustand
- **Data Fetching**: React Query (TanStack Query)
- **Forms**: React Hook Form + Zod
- **Date Handling**: date-fns
- **Icons**: Lucide React
- **i18n**: i18next + react-i18next
- **Mocking**: MSW (Mock Service Worker)
- **Testing**: Vitest + Playwright + Testing Library

## RULE
- Use the existing technology stack.
- DO NOT migrate React to Next.js or Vite to another bundler.
- DO NOT add a new CSS framework.
- DO NOT add a new state management library if Zustand/React Query is sufficient.
- DO NOT install unnecessary dependencies without explicit request.
