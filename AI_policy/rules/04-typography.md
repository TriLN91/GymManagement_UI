# 04. TYPOGRAPHY SYSTEM

## FONTS
- **Syne**: Brand, Landing, Hero, Marketing, Display heading. DO NOT use for general application UI.
- **Plus Jakarta Sans**: Member UI, Trainer UI, Everyday UI, Navigation, Body text, Forms. (Main UI font).
- **Barlow**: Fitness metrics (Weight, Height, Load, Reps, Sets, Duration, Distance).
- **Space Grotesk**: AI, Analytics, Smart features, Technical performance information.
- **IBM Plex Sans**: Admin UI, Dense data, Tables.

## TYPOGRAPHY RULE
- Do not mix too many fonts in one component.
- Ensure clear typography hierarchy based on the roles above.
