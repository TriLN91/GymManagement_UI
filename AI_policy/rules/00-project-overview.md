# 00. PROJECT OVERVIEW

## FRONTEND ONLY
- This project scope is strictly FRONTEND ONLY.
- DO NOT modify the backend, database, schema, or API contracts unless explicitly requested.
- If an API does not exist, use mock data, mock services, or local state. Do not pretend the mock is a real API.

## DO NOT DESTROY EXISTING WORK
- Do not overwrite the entire project or rewrite the whole app.
- Do not delete unrelated old components/pages.
- Changes should be minimal. If refactoring is needed, explain the reason and scope first.
- Preserve existing component systems, layouts, and utilities.

## REUSE BEFORE CREATE
- Before creating a new file, search for existing similar components (Button, Card, Input, Modal, Sidebar, Table, Badge, etc.).
- REUSE existing components. Do not create new variants (e.g. `CustomButton`, `ModernButton`) just for a minor difference.
