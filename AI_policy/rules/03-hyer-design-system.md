# 03. HYER DESIGN SYSTEM

## CORE COLORS
- **Forest Green (`#345C32`)**: Primary color, primary text, heading, sidebar, navigation, primary button, brand backbone.
- **Pure White (`#FFFFFF`)**: Main canvas, page background, cards, input surfaces, clean content areas.
- **Mint (`#A7F0DD`)**: THE ONLY ACCENT COLOR. Used for active navigation, selected state, AI indicator, important CTA. DO NOT add other accent colors.
- **Cool Ash (`#97CD97`)**: Secondary text, subtle background, disabled/subtle UI.
- **Pebble (`#9CAC54`)**: 1px borders, dividers, subtle structural separation.

## COLOR RESTRICTIONS
- ABSOLUTELY NO `#000000` as primary UI color.
- NO Navy, Purple, Blue, Orange, Red, Pink, or random gradients.
- Keep semantic states (error, warning, success) subtle. Do not turn them into brand accents.

## SHAPE SYSTEM (SQUARE + PILL)
- **STRUCTURE = SQUARE**: Cards, Sections, Images, Inputs, Tables, Panels. Use `rounded-none` or very minimal radius.
- **INTERACTION = PILL**: Buttons, Nav items, Badges, Chips, Toggles, Tabs. Use `rounded-full`.

## NO GENERIC AI UI
- Avoid glassmorphism, neumorphism, heavy gradients, floating glass cards, excessive blur, or huge rounded containers.
- The design must feel Premium, Editorial, Fitness Performance, Professional, Clean, Structured, and Intentional.
